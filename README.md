# 保安管理 点検記録

高圧受電設備の点検を、現場のスマホで「記録」と「参照」まで完結させるオフラインアプリ。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 本体（HTML / CSS / JS すべてインライン、外部依存なし） |
| `manifest.json` | PWA マニフェスト（アイコンは data URI 埋め込み） |
| `sw.js` | Service Worker（キャッシュ優先でオフライン起動）。更新時は `CACHE` の版数を上げる（現在 `hoan-v3`） |

データは `localStorage`（キー `hoan.sites.v1`）、表示テーマは `hoan.theme` に保存。通信は一切発生しない。

## GitHub Pages で公開する

1. GitHub でリポジトリを作成し、この3ファイルをリポジトリ直下に置く
2. Settings → Pages → Source を `main` / `(root)` に設定
3. 発行された `https://<ユーザー名>.github.io/<リポジトリ名>/` をスマホで開く
4. ブラウザメニューから「ホーム画面に追加」→ 以降は電波がなくても起動する

ローカル確認だけなら `index.html` をそのまま開けば動く（Service Worker は http/https のときだけ登録される）。

## 判定基準の変更

判定値はすべて `index.html` 冒頭の `CRITERIA` オブジェクトに集約してある。基準改訂や社内ルールの差異は、原則ここ1箇所の書き換えで全画面・テキスト出力・リファレンスに反映される。

```js
var CRITERIA = {
  ground:    { A:10, C:10, D:100, fastBreak:500, elb:500, aux:1000, refOnlyKinds:[...], ... },
  hv:        { cableG:{...}, cableE:{...}, busE:{ok:5, ng:0.1, weakRatio:3}, ... },
  withstand: { factor:1.5, dcFactor:2, minutes:10, maxUseRatio:1.15/1.1 },   // 耐圧試験
  relay: {                              // 継電器種別 × 試験種別 の2階層
    OCR:  { "年次点検":{...}, "竣工試験":{...} },
    GR:   { "年次点検":{...}, "竣工試験":{ taps:[0.1〜1.0], ... } },
    OVR:  { "年次点検":{...}, "竣工試験":{ classes:{"2.5V級":{...},"5V級":{...}}, ... } },
    OVGR: { "年次点検":{...}, "竣工試験":{ variants:{ JEC:{...}, OMRON:{...} } } },
    RPR:  { "竣工試験":{ variants:{ A:{...}, B:{...} } } },
    UPR / UFR / DSR / DIF / MPR / LGR / LFA: { "竣工試験":{...} }
  },
  lv: { classes:{...}, megger:{...}, leakMax:1.0 }
};
```

- 基準は `RC(種別, 試験種別)` で引く。片方の試験種別しか定義が無い種別は、もう一方でも同じ定義を使う
- `variants` を持つ種別（OVGR竣工・RPR）は、整定欄の「判定基準（記録雛形）」で雛形を選ぶ。`relayK()` が選択中の雛形を合成して返す
- DGR は `RELAY_ALIAS` で GR の基準を共用する（竣工は高圧地絡の様式＋方向要素）

内蔵値の一覧はアプリ内 リファレンス →「判定基準の一覧」「竣工試験の様式」でも確認できる。

## 継電器（14種）と記録雛形

`Second Brain/raw/★継電器_試験記録雛形.md` の試験記録雛形14件を反映している。

| 継電器 | 雛形・判定基準 | 主な判定 |
|---|---|---|
| OCR（51） | JIS C 4602（保No.3071） | 最小動作 限時±10%・瞬時±15%／瞬時 単体0.05s以下／限時動作時間は記録（期待値 (D/10)×T10.3 を補助表示） |
| GR（51G） | JIS C 4601・4607（保No.3061） | **全タップ 0.1〜1.0A** で±10%／130% 単体0.1〜0.3s・連動0.4s以内／慣性 400%×0.05sで不動作 |
| DGR（67） | 上記＋方向要素 | GRの項目＋最小動作電圧±25%・位相（メーカー範囲） |
| OVR（59）／UVR（27） | JEC 2511・2520（保No.3081） | **2.5V級 ±2.5%／5V級 ±5%**。電圧タップ最小値（UVRは最大値）と整定値で測る。復帰 97.5/95%以上（UVRは102.5/105%以下）。時間 10T級±10% |
| OVGR（64） | JEC 2511（1321）／メーカー管理値オムロン | JECは形式・階級で判定（誘導形 ±5%・復帰80%、静止形2.5V級 ±2.5%・92.5%、5.0V級 ±5%・85%／時間は 2.5T・5T・10T 級または誘導形200%±15%）。オムロンは ±25%・時間±5%（最小誤差50ms） |
| RPR（67P） | メーカー管理値オムロン（1391） | 位相180°で基準値の95%。**雛形A＝±5%・時間±10%、雛形B（記録雛形-10）＝±10%・時間±20%** を選択 |
| UPR（37） | メーカー管理値オムロン（1401） | 位相0°で基準値の105%±5%／時間±10%（最小誤差50ms） |
| UFR（95L） | メーカー管理値オムロン（1371） | 動作周波数 整定±0.1Hz／5Hz降下で時間±20% |
| DSR（67S） | メーカー管理値オムロン（1381） | 最小動作電流・不足動作電圧・動作時間 各±20%（R/S/T）／位相特性は記録 |
| 比率差動（87） | メーカー管理値（1361） | 判定欄は空欄。**比率計算値（抑制電流15A時）を自動計算**、許容差を入れれば判定 |
| 回転機保護（3E） | メーカー管理値（1411） | 判定欄は空欄＝記録（過電流・逆相・欠相U/V/W × 最小動作電流・200%・500%） |
| LGR | JIS C 8374（保No.3091） | タップ値の **50〜100%** で動作＝良（子機 M・1〜9 ごとに記録） |
| 漏電火災警報器 | 消防予 第282号（保No.3091） | タップ値の **40〜105%** で動作＝良（子機ごと） |

竣工試験では各様式の共通欄（トリップテスト／動作表示／外観点検／警報装置（現場・遠方）／総合判定、GRはテストボタン・SOGテスト、電圧系はテストボタン）が加わる。判定は ○＝良・×＝不良・—＝該当なし。

**基準値の手入力が必要なもの**：OCRの公称動作時間 T10.3／OVGR の公称動作時間（JEC）・動作電圧整定[V]（オムロン）／RPR・UPR の動作電流基準値[A]（整定電力%の換算値）／OVR・UVR の電圧タップ最小値・最大値と時間タップ最大値。

## 試験種別（年次点検 / 竣工試験）

現場ごとに **年次点検 / 竣工試験** を持つ（新規作成時に選択、種別を「竣工」にすると自動で竣工試験。現場詳細から後で変更可）。継電器タブの様式と判定基準がこの軸で切り替わる。整定値・測定値は `relay.byKind[試験種別]` に分けて保存するので、切り替えても互いの入力は消えない（器具番号とメモは種別共通）。

竣工試験のときは高圧絶縁タブに **耐圧試験** の記録欄が出る。受電電圧から最大使用電圧（×1.15/1.1）と試験電圧（交流×1.5、ケーブルは直流×2）を自動計算し（6.6kV系 → 交流10,350V・直流20,700V、10分）、PAS開放・3線一括・SOG P1-P2切り離しの確認チェックを付ける。

## 入力UIの考え方

- 測定タブは **1行＝1項目**。行には名称・測定値・判定バッジだけを出し、詳細は行タップ（低圧は ⚙）で展開する
- 継電器は1台＝1カード。見出しに **判定サマリー（最悪判定）と入力数**（例：`入力 9/18`）を出し、タップで畳める
- 整定値（判定に効く数値・選択）と **銘板・試験器**（文字欄）を分け、銘板側は既定で畳む
- %別の動作時間は **1つの表**（行＝%、列＝単体／連動 × 相）。列が複数の表は判定バッジを入力欄の下に置き、入力欄の幅を確保する
- LGR の子機・OVGR の試験整定・UFR の整定値などは **繰り返し記録**（追加・削除できるカード）
- ○×の確認項目は2列グリッド
- タブには区分内に **要注意・不良があると点** が付き、現場一覧のカードにも「不良あり／要注意あり」が出る

## 接地・高圧・低圧・その他

- 接地抵抗：新規現場に A種 / B種 / C種 / D種 / D種(ELB) / PAS / 補助極(P) / 補助極(C) / 鉄骨 の9行。補助極・鉄骨は「参考値」で進捗の必須に数えない
- 高圧絶縁：3線一括。E方式は5kV・10kVの2点、弱点比（5kV÷10kV）を自動算出してタブ上部に大きく表示（2.5以上＝注意色、3以上＝赤）。標準3測定（負荷側E／電源側G／電源側E）はいずれも母線・機器。危険ケーブルは10kV欄を無効化
- 低圧：B種接地線クランプは Igr で1mA以下（電灯・動力トランスが既定）。回路の詳細に対地電圧区分ごとの推奨メガーレンジを表示
- その他：**変圧器 内部点検**（パッキン・油量・油色・タップ・異物・ユニチェックの○×、LGR試験と3年周期で交互）と自由メモ

## デザイン

配色はすべて CSS 変数（`:root` のトークン）で定義し、**ライト／ダーク**の両方を持つ。設定画面で「自動／ライト／ダーク」を切り替えられる（自動は端末設定に追従）。判定色（良＝緑・要注意＝黄・不良＝赤）はバッジと強調表示に限定し、アクセントは青1色。アイコンは線画SVG。

## データ移行（旧版からの互換）

`migrateSite()` が読み込み時に不足フィールドを補う。既存の測定値は書き換えない。

- 旧LGR（`setI`・`opI`・`opTime` の単票）→ 子機一覧の1台目（番号M）へ移す
- 既存の竣工OVGR記録 → 判定基準を「オムロン」に固定（入力時の判定を保つ）。新規は JEC 2511 が既定
- 旧形式（継電器の `s`/`m` 直持ち、`bClamp` 単体、`testKind` 無し）も従来どおり補完

## 注記

自動判定は入力値と内蔵基準による補助機能。最終判断は有資格の技術者が行うこと（メーカー仕様書・電力会社との協議を優先）。
`localStorage` 依存のため、定期的に JSON エクスポートでバックアップを取ること。
