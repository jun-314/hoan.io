# 保安管理 点検記録

高圧受電設備の点検を、現場のスマホで「記録」と「参照」まで完結させるオフラインアプリ。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 本体（HTML / CSS / JS すべてインライン、外部依存なし） |
| `manifest.json` | PWA マニフェスト（アイコンは data URI 埋め込み） |
| `sw.js` | Service Worker（キャッシュ優先でオフライン起動） |

データは `localStorage`（キー `hoan.sites.v1`）に保存。通信は一切発生しない。

## GitHub Pages で公開する

1. GitHub でリポジトリを作成し、この3ファイルをリポジトリ直下に置く
2. Settings → Pages → Source を `main` / `(root)` に設定
3. 発行された `https://<ユーザー名>.github.io/<リポジトリ名>/` をスマホで開く
4. ブラウザメニューから「ホーム画面に追加」→ 以降は電波がなくても起動する

ローカル確認だけなら `index.html` をそのまま開けば動く（Service Worker は http/https のときだけ登録される）。

## 判定基準の変更

判定値はすべて `index.html` 冒頭の `CRITERIA` オブジェクトに集約してある。基準改訂や社内ルールの差異は、原則ここ1箇所の書き換えで全画面に反映される。

```js
var CRITERIA = {
  ground: { A: 10, C: 10, D: 100, fastBreak: 500, ... },
  hv:     { cableG: {ok:10, warn:1}, busE: {ok:5, ng:0.1, weakRatio:3}, ... },
  relay:  { OCR: {limTol:10, instTol:15, ...}, GR: {...}, OVR: {...}, ... },
  lv:     { classes: {...}, leakMax: 1.0 }
};
```

内蔵値の一覧は アプリ内 リファレンス →「判定基準の一覧」でも確認できる。

## 実装済みの機能

- 現場一覧（検索 / 直近順 / 進捗率と未入力チップ）
- 現場詳細タブ：接地抵抗 / 高圧絶縁 / 継電器試験 / 低圧絶縁・漏洩 / 自由メモ
- 自動判定（良・要注意・不良のバッジ）、整定値から判定範囲を自動表示
- 継電器：OCR・GR・DGR・OVR・UVR・OVGR・LGR
- リファレンス（SOG結線・CTT結線・耐圧試験・測定器の使い方・CT/VT禁止事項ほか）
- JSON エクスポート / インポート、1現場分のテキスト書き出し（コピーボタン付き）
- 同一現場名の前回記録との比較（前回値と増減の表示）、前回整定値の読込
- PWA（ホーム画面追加でオフライン起動）

## 注記

自動判定は入力値と内蔵基準による補助機能。最終判断は有資格の技術者が行うこと。
`localStorage` 依存のため、定期的に JSON エクスポートでバックアップを取ること。
