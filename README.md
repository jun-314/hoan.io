# 保安管理 点検記録（v3.0）

高圧受電設備（キュービクル・PAS）の点検・試験を、現場でスマホから記録して自動判定するオフライン対応アプリです。
判定は補助機能です。最終判断は技術者が行ってください。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（HTML・CSS・JS をすべて内蔵。外部ライブラリなし） |
| `manifest.json` | ホーム画面に追加するための設定 |
| `sw.js` | オフライン起動用のキャッシュ |
| `img/` | 資料に載せる写真（24枚・約1.8MB）。無くてもアプリは動く |

## GitHub Pages への公開

1. リポジトリに上の4つ（`img` フォルダごと）をアップロードする。
2. Settings → Pages → Branch を `main` / `(root)` にして保存。
3. 表示された URL をスマホで開き、「ホーム画面に追加」する。

- 更新したら `sw.js` の `CACHE`（現在 `hoan-v4`）の番号を上げる。上げないと古い画面がキャッシュから出続ける。
- `img/` の写真は公開されます。管理番号・号車・校正シールは塗りつぶし済みですが、公開前に一度確認してください。

## 画面

下部のドックで4画面を切り替えます。

| 画面 | 内容 |
|---|---|
| 現場 | 現場の一覧と作成。進捗リング・判定・未入力の区分を表示 |
| 計算 | 耐圧試験の充電電流（対地静電容量から計算）／％・許容範囲の早見 |
| 資料 | 結線・手順・判定基準・写真。検索と分類で絞り込み |
| 設定 | テーマ（自動／ライト／ダーク）、JSON の書き出し・読み込み |

現場を開くと、接地／高圧／継電器／低圧／その他の5タブで入力します。現場名をタップすると現場情報（名前・電圧・日付・種別・試験種別）を編集できます。

## 記録できる項目

- **接地抵抗**：A・B・C・D・D(ELB)・PAS・補助極・鉄骨。B種は 150／300／600 ÷ 1線地絡電流で基準値を計算。
- **高圧絶縁抵抗**：標準3測定（負荷側E → 電源側G → 電源側E）。E方式は 5kV・10kV の2点で弱点比を自動計算。危険ケーブルは5kVまで。
- **耐圧試験（竣工のみ）**：試験電圧の自動計算、印加前チェック、充電電流の見込み計算と実測の比較。
- **継電器試験**：14種（OCR・DSR・GR・DGR・OVGR・OVR・UVR・UFR・RPR・UPR・比率差動・回転機保護・LGR・漏電火災警報器）。
  試験種別（年次点検／竣工試験）で様式と基準が切り替わり、値は種別ごとに別々に保持される。
- **低圧**：B種接地線の漏えい電流（Igr）、回路ごとの絶縁抵抗と漏えい電流。
- **その他**：変圧器の内部点検、自由メモ。

### 継電器の入力欄（v3）

整定欄は**試験と判定に使う値だけ**です。レバー・CT比・銘板・試験器などの欄は廃止しました（保存済みの値はデータに残ります）。
○×の確認はボタンを1回タップで ○、続けて ×、—、未入力 と切り替わります。

OCR の動作時間は、年次点検では小数第2位まで、竣工試験では小数第3位まで読みます。桁が違う入力には「桁を確認」と表示します（判定は変えません）。

## 充電電流の計算（計算タブ・耐圧試験カード）

- Ic ＝ 2πfCV（V は試験電圧そのまま）、試験容量 ＝ V × Ic。
- ケーブル：6600V CV・CVT の1心あたり静電容量 × こう長 × 3（3線一括）。メーカーカタログ（JIS C 3606 品）の参考値。
- 変圧器：油入／モールド × 単相／三相 × 容量の目安表、手入力 pF、または簡易則（100kVA あたり約10mA）。
  **変圧器の表は出典を確認できていない目安値**で、メーカー・機種で変わります。
- 試験器の許容充電電流との比較、リアクトル補償後の負担電流、低電圧実測からの換算も表示します。

## 判定基準（CRITERIA）

`index.html` 冒頭の `CRITERIA` オブジェクトに、判定値・試験条件・計算用の表をすべて集めています。基準を変えるときはここだけ直します。

| キー | 内容 |
|---|---|
| `ground` | 接地抵抗の基準、B種の係数、地電圧の上限 |
| `hv` | 高圧絶縁（ケーブルG・E、シース、母線・機器、弱点比） |
| `withstand` | 耐圧試験（7,000V以下は×1.5、超は×1.25・最低10,500V、直流は×2、10分） |
| `cap` | 充電電流の計算（ケーブル・変圧器の静電容量表、試験器の許容電流、差の警告％） |
| `relay` | 継電器14種 × 試験種別（年次点検／竣工試験）の許容差・試験条件。OCR は `timeDec`（時間を読む桁） |
| `lv` | 低圧絶縁、漏えい電流 |

主な基準：LGR・漏電火災警報器の年次は整定値の40〜100%（社内基準）。竣工は LGR 50〜100%（JIS C 8374）、漏電火災警報器 40〜105%（消防予第282号）。

## データ

- 現場データは端末の localStorage（キー `hoan.sites.v1`）に保存。計算タブの入力は `hoan.tools.v1`、テーマは `hoan.theme`。
- 旧バージョンのデータはそのまま読めます（`migrateSite()` が不足項目を補うだけで、測定値は書き換えません）。
- 機種変更やバックアップは、設定 → JSON エクスポート／インポートで行います。

## デザイン

- 墨（黒）＋白＋群青を基調にし、緑・黄・赤は判定だけに使う。ライト／ダーク対応。
- 判定バッジは色に加えて記号（✓・!・×）と文字で示す。
- タップ領域は44px以上。入力中は下部のドックを隠して画面を広く使う。
- 画面・タブの切り替え時と、判定が変わったときだけ短いアニメーションを付ける（端末の「視差効果を減らす」設定に従う）。

## 開発メモ

- 確認用サーバ：`node .claude/serve-hoan-app.mjs 8125`（Obsidian フォルダ直下から）。`localhost` では Service Worker を登録しない。
- Service Worker を試すときは `http://127.0.0.1:8125/` で開く。
