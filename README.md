# 保安管理 点検記録

高圧受電設備の点検を、現場のスマホで「記録」と「参照」まで完結させるオフラインアプリ。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 本体（HTML / CSS / JS すべてインライン、外部依存なし） |
| `manifest.json` | PWA マニフェスト（アイコンは data URI 埋め込み） |
| `sw.js` | Service Worker（キャッシュ優先でオフライン起動） |

データは `localStorage`（キー `hoan.sites.v1`）に保存。通信は一切発生しない。

## GitHub Pages で公開する

1. GitHub でリポジトリを作成し、この3ファイルをリポジトリ直下に置く
2. Settings → Pages → Source を `main` / `(root)` に設定
3. 発行された `https://<ユーザー名>.github.io/<リポジトリ名>/` をスマホで開く
4. ブラウザメニューから「ホーム画面に追加」→ 以降は電波がなくても起動する

ローカル確認だけなら `index.html` をそのまま開けば動く（Service Worker は http/https のときだけ登録される）。

## 判定基準の変更

判定値はすべて `index.html` 冒頭の `CRITERIA` オブジェクトに集約してある。基準改訂や社内ルールの差異は、原則ここ1箇所の書き換えで全画面に反映される。

```js
var CRITERIA = {
  ground: { A:10, C:10, D:100, fastBreak:500, elb:500, aux:1000,
            refOnlyKinds:["AUXP","AUXC","STEEL"], ... },
  hv:     { cableG:{ok:10,warn:1}, busE:{ok:5,ng:0.1,weakRatio:3}, ... },
  relay:  {                                  // 継電器種別 × 試験種別 の2階層
    OCR:  { "年次点検":{limTol:10, instTol:15, testMultiplier:2.0, ...},
            "竣工試験":{limSteps:[300,700], instStep:200, instTimeMax:0.05, ...} },
    OVGR: { "年次点検":{vTol:5, ...}, "竣工試験":{vTol:25, timeSteps:[120,150], ...} },
    RPR:  { "竣工試験":{basePct:95,  judgePhase:180, phaseSteps:[120,180,-120], ...} },
    UPR:  { "竣工試験":{basePct:105, judgePhase:0,   phaseSteps:[60,0,-60], ...} },
    GR:   { "年次点検":{...} }, DGR/OVR/UVR/LGR も同様
  },
  lv:     { classes:{...}, leakMax:1.0 }
};
CRITERIA.hv.weakDisplay = { warn: 2.5, ng: CRITERIA.hv.busE.weakRatio }; // 弱点比カードの強調しきい値
```

継電器の基準は `RC(種別, 試験種別)` で引く。竣工の定義が無い種別は年次にフォールバックする。

主な定数の意味：

| キー | 用途 |
|---|---|
| `ground.elb` | D種(ELB) の緩和値 [Ω] |
| `ground.refOnlyKinds` | 判定対象外（参考値）とする種別。進捗の必須項目からも外れる |
| `hv.weakDisplay` | 弱点比カードの色分けしきい値。`ng` は判定基準 `busE.weakRatio` を参照するので二重管理にならない |
| `relay.OCR.testMultiplier` | OCRの試験電流倍率。`2.0` なら 200%。ラベルも200%値の表示もこの1箇所から生成される |

内蔵値の一覧は アプリ内 リファレンス →「判定基準の一覧」でも確認できる。

## 実装済みの機能

- 現場一覧（検索 / 直近順 / 進捗率と未入力チップ / 現場ごとの個別削除）
- 現場詳細タブ：接地抵抗 / 高圧絶縁 / 継電器試験 / 低圧絶縁・漏洩 / 自由メモ
- 自動判定（良・要注意・不良のバッジ）、整定値から判定範囲を自動表示
- 継電器：OCR・GR・DGR・OVR・UVR・OVGR・LGR
- リファレンス（SOG結線・CTT結線・耐圧試験・測定器の使い方・CT/VT禁止事項ほか）
- JSON エクスポート / インポート、1現場分のテキスト書き出し（コピーボタン付き）
- 同一現場名の前回記録との比較（前回値と増減の表示）、前回整定値の読込
- PWA（ホーム画面追加でオフライン起動）

## 入力UIの考え方

継電器タブは、%別の動作時間を **1つの表**（行＝%、列＝単体／連動 × R相／T相）にまとめ、R相・T相は1行に並べ、○×のチェック項目は2列に詰める。見出し・追加UI・注記はタブの末尾に置き、測定入力欄が最初に来る。年次点検の各継電器と竣工試験のOVGR/RPR/UPRは測定欄が1画面に収まる（竣工試験のOCRは入力24箇所のため約1.5画面）。

現場でのスクロールを減らすため、測定タブは **1行 = 1項目** の一覧で、行には「名称・測定値・判定バッジ」だけを出す。種別／測定方式／地電圧／備考／削除などの詳細は、**行をタップ（低圧回路は ⚙）して展開**する。現場情報カードと継電器の整定値も既定で折りたたみ、測定値の入力欄が最初から画面に並ぶようにしてある。

接地抵抗は新規現場に **A種 / B種 / C種 / D種 / D種(ELB) / PAS / 補助極(P) / 補助極(C) / 鉄骨** の9行がこの順で入る（削除・追加は自由）。PAS はA種と同じ基準で判定する。補助極(P)・補助極(C)・鉄骨は判定対象外で「参考値」バッジを表示し、未入力でも進捗率・未入力チップに影響しない。

高圧絶縁は3線一括のみを記録する。E方式は 5kV と 10kV の2点を入力でき、行の総合判定は悪いほうを採る。新規現場には「負荷側 E方式／電源側 G方式／電源側 E方式」の3測定がこの順で入り、**いずれも測定箇所は「母線・機器」**（電源側で測っているのは機器・母線のため）。したがって判定は母線・機器の基準（5GΩ以上=良／0.1〜5GΩは弱点比3未満=良・以上=要注意／0.1GΩ未満=不良）を使う。ケーブル絶縁体・シースを測る場合は行の ⚙ から測定箇所を変更する。

**危険ケーブル**（5kVを超える電圧を印加してはならないケーブル）は、ケーブルのG方式・E方式の行で詳細を開いてチェックする。10kV欄がグレーアウトして入力不可になり、判定は5kV値のみ、弱点比は「算出不可（5kVのみ）」になる。既に10kV値が入っている行にチェックを入れても値は破棄せず、判定と弱点比から除外したうえで警告を表示する。

弱点比は **同じ測定点の 5kV値 と 10kV値 の比**（大きい方÷小さい方）を自動算出する。電源側は電源側の5kV/10kV、負荷側は負荷側の5kV/10kVで取り、3以上で要注意。タブ上部の専用カードに測定側ごとに大きく常時表示し、3.0以上は赤、2.5〜3.0未満は注意色、それ未満は通常色で表示する。母線・機器の判定にも使う。行を開いて手入力すればそちらが優先され、カードに「手入力」バッジが付く。

OCR の整定値欄（限時タップ・瞬時整定）には、入力した時点で試験電流の 200% 値が赤字で自動表示される（例：`200% = 12.0A`）。表示専用で、保存データには整定値しか持たない。

## 試験種別（年次点検 / 竣工試験）

現場ごとに **年次点検 / 竣工試験** を持ち（新規作成時に選択、現場詳細から後から変更可）、**継電器タブの入力欄・判定基準がこの軸で切り替わる**。現場一覧と現場詳細にチップで表示する。種別を持たない既存データは「年次点検」として扱う。

整定値・測定値は `relay.byKind[試験種別]` に**種別ごとに分けて保存**されるので、切り替えても互いの入力は消えない（器具番号とメモは種別共通）。

| 継電器 | 竣工試験の様式 |
|---|---|
| OCR | JIS C 4602。限時 単体は 150/200/300/500/700%、限時 CB連動は 300/700%、瞬時は200%。最小動作電流のみ自動判定（限時±10%・瞬時±15%）、瞬時 単体の動作時間は0.05秒以下。他の動作時間は記録のみで、公称動作時間 T10.3 から期待値 `(D/10)×T10.3` を併記。各%の試験電流は整定値から自動計算して行見出しに表示 |
| OVGR | メーカー管理値。動作電圧 ±25%（年次の±5%と異なる）、動作時間は120%/150%で ±5%（最小誤差±50ms）。復帰値は記録のみ |
| RPR（逆電力） | 位相 +120/+180/−120°、判定は+180°で基準値の95%±5%。動作時間 ±10%。単体・連動の2系統 |
| UPR（不足電力） | 位相 +60/0/−60°、判定は0°で基準値の105%±5%。動作時間 ±10%（最小誤差±50ms）。単体・連動の2系統 |
| GR / DGR / OVR / UVR / LGR | **記録雛形が無いため年次点検と同じ項目**（継電器タブに注記を表示） |

竣工試験では4様式に共通する欄（回路名・製造者・製造年・型式・製造番号／トリップテスト・動作表示・外観点検・警報装置（現場・遠方）・総合判定）が加わる。判定は ○＝良・×＝不良・—＝該当なし。

RPR/UPR の判定に使う **動作電流の基準値[A]**（整定電力[%]からの換算値）は整定欄に手入力する。

B種接地線のクランプ測定は Igr で判定し、既定で「電灯トランス」「動力トランス」の2行が入る。行はいくつでも足せる。Io と備考は ⚙ から入力する。

## 注記

自動判定は入力値と内蔵基準による補助機能。最終判断は有資格の技術者が行うこと。
`localStorage` 依存のため、定期的に JSON エクスポートでバックアップを取ること。
